# 资料口径

主体、设备和数值全部合成，不代表真实企业或实验结果。CSV 为 UTF-8，空值表示未知或不适用，不能当成零；布尔为 true/false。日期采用 ISO 格式，时刻带 +08:00 时区；日期区间左闭右开。金额为人民币元，概率为 0–1，除字段另有声明外数量为非负。CSV 排序不代表事件顺序。available_at 表示该事实最早可知时刻，历史截点不可使用较晚才知的值。样本用于开发，业务结论未预设。

kit_key与component_key为命名空间加本地号的合成业务键，serial只在manufacturer内唯一。型号按version生效，required=true类至少quantity件，choice_group非空同组最多quantity件，可选类不影响完整性。assembly仅表示装配关系，不证明转移位置；shipment整套扫描与scan带同shipment_id的组件证据为同次交付。loan是临时使用权，sale是永久销售；服务中断由已交客户的必需件缺少或nonworking决定，不冲销销量。换件闭合须原件卸下、新件装入且各自位置一致；缺回库扫描保持在途或未知。quality_events有时点且状态持续至后续事件，不是当前状态覆盖全部历史。

## components
单件身份。

记录键：['component_key']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| component_key | string | 完整键 |
| manufacturer | string | 厂商 |
| serial | string | 本地号 |
| class | string | 部件类 |
| lot | string | 制造批 |

## kits
整套身份。

记录键：['kit_key']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| kit_key | string | 套键 |
| model | string | 型号 |
| version | string | 组成版 |

## composition_rules
所需组成。

记录键：['rule_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| rule_id | string | 规则 |
| model | string | 型号 |
| version | string | 版 |
| class | string | 类 |
| required | boolean | 必需 |
| quantity | integer | 件数 |
| choice_group | string | 互斥组 |

## assembly
装配经历。

记录键：['assembly_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| assembly_id | string | 关系 |
| kit_key | string | 套 |
| component_key | string | 件 |
| start | datetime | 装入 |
| end | datetime | 卸下 |
| basis | string | permanent或loan |

## shipments
套交付单。

记录键：['shipment_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| shipment_id | string | 发运 |
| kit_key | string | 套 |
| customer | string | 客户 |
| kind | string | sale或loan |
| at | datetime | 时点 |

## scans
实际位置变化；同单同件扫描是证据而非额外销量。

记录键：['scan_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| scan_id | string | 扫描 |
| component_key | string | 件 |
| shipment_id | string | 交付或空 |
| from_location | string | 起 |
| to_location | string | 止 |
| at | datetime | 时点 |

## quality_events
状态经历。

记录键：['event_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| event_id | string | 事件 |
| component_key | string | 件 |
| state | string | working或nonworking |
| at | datetime | 时点 |

同一来源记录键的新文件表示整行修订，调用者明确接收次序；原始文件和接收历史须保留。相同文件摘要不增加事实。下面标为后续接收的文件不随基础资料自动生效，用户可分次装载。历史事实的业务时点与本次接收时点分开。金额除另述外人民币元，结算舍入到分的尾差归该账单分摊基数最大项，并列按业务键升序。本文规定来源语义，不规定待开发仓表、算法或架构。

开局所有单件位置store、working。assembly仅装配不表示发运。服务中断由必需件缺少或nonworking造成，合规可用借件恢复服务但不增加销量。制造批追查按查询时点的实际装配及位置。
